# YouTube M3U8 Link Extractor Worker

Bu proje, YouTube canlı yayın linklerini ve kanal ID'lerini doğrudan IPTV oynatıcıların (VLC, TiviMate vb.) oynatabileceği **M3U8** akış adreslerine dönüştürür.

## Kullanım

Worker adresinizin sonuna `?url=` parametresiyle YouTube linkini ekleyin:

```text
https://youtube-m3u8-worker.KULLANICI_ADINIZ.workers.dev/?url=https://youtube.com
```
